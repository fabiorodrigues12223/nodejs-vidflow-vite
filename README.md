# 🎬 VidFlow

Plataforma de vídeos inspirada no YouTube, com navegação por menu lateral, busca e filtro por categorias. Os vídeos são carregados dinamicamente a partir de uma API.

🔗 **Acesse o projeto:** [nodejs-vidflow-vite-xi-eight.vercel.app](https://nodejs-vidflow-vite-xi-eight.vercel.app/)


---

## ✨ Funcionalidades

- 📺 Listagem de vídeos carregados dinamicamente de uma API
- 🔍 Campo de busca para encontrar vídeos pelo título
- 🏷️ Filtro por categorias (Front-end, Mobile, Data Science, Programação, Inteligência Artificial e outras)
- 📂 Menu lateral com Início, Explorar, Shorts, Inscrições e Biblioteca
- 👥 Lista de canais inscritos
- 📱 Layout responsivo, adaptado para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- **HTML5** – estrutura da página
- **CSS3** – estilização e responsividade
- **JavaScript** – consumo da API com `fetch` e `async/await` e manipulação do DOM
- **Node.js** – ambiente de desenvolvimento
- **Vite** – ferramenta de build e servidor de desenvolvimento
- **Vercel** – hospedagem e deploy

## 🚀 Como rodar o projeto localmente

Pré-requisito: ter o [Node.js](https://nodejs.org/) instalado.

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git

# Entre na pasta do projeto
cd NOME-DO-REPOSITORIO

# Instale as dependências
npm install

# Rode o projeto em modo de desenvolvimento
npm run dev
```

Depois, abra no navegador o endereço que aparecer no terminal (normalmente `http://localhost:5173`).

## 📚 O que aprendi

- Consumir dados de uma API com JavaScript usando `fetch` e `async/await`
- Tratar erros nas requisições com `try/catch`
- Criar elementos na página de forma dinâmica a partir dos dados recebidos
- Implementar busca e filtros com JavaScript
- Configurar um projeto com Vite e publicar na Vercel
